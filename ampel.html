Grundlagen: LED und Vorwiderstand

Eine LED ist keine kleine Glühlampe. Sie hat eine Richtung und braucht Strombegrenzung.

LED: Anode oder Kathode?

Eselsbrücke: A wie Anode = Anschluss an Plus. K wie Kathode = kurzes Bein = Minus.

Warum braucht die LED einen Vorwiderstand?

Der Arduino-Ausgang liefert ungefähr 5 V. Eine rote LED benötigt etwa 2 V. Der Rest der Spannung fällt am Widerstand ab. Der Widerstand begrenzt den Strom, damit LED und Arduino-Pin nicht überlastet werden.

U = R · I    |    I = U / R

Beispiel: Am Widerstand fallen etwa 3 V ab. Bei 220 Ω ergibt sich:

I = 3 V / 220 Ω ≈ 0,0136 A = 13,6 mA

guter Bereich: ca. 13,6 mA

Ohne Vorwiderstand kann eine LED kurz sehr hell sein – und dann sehr dauerhaft aus.

2

Der Schaltaufbau

Pins, LEDs, Widerstände und GND werden sauber verbunden. Sauber ist hier nicht Geschmacksfrage, sondern Überlebensstrategie für Bauteile.

Vereinfachter Aufbau

Aufbau in vier Schritten

1Stecke jede LED so ein, dass Anode und Kathode nicht in derselben 5er-Bahn sitzen.
2Verbinde die Anode der roten LED mit Pin 13, gelb mit Pin 12, grün mit Pin 11.
3Verbinde jede Kathode über einen eigenen 220-Ω-Widerstand mit GND.
4Prüfe: Kein LED-Bein steckt versehentlich in derselben verbundenen Reihe wie das andere.

Richtig ist: Arduino-Pin → Anode (+) und Kathode (−) → Widerstand → GND.

3

Der Arduino-Code

Der Code schaltet die drei Pins nacheinander ein und aus. Die loop()-Funktion wiederholt das Ganze endlos.

Vollständiger Arduino-Sketch
// Arduino-Ampelschaltung Klasse 9
// Rot: Pin 13, Gelb: Pin 12, Grün: Pin 11

const int ROT = 13;
const int GELB = 12;
const int GRUEN = 11;

void setup() {
  pinMode(ROT, OUTPUT);
  pinMode(GELB, OUTPUT);
  pinMode(GRUEN, OUTPUT);
}

void loop() {
  // Phase 1: Rot
  digitalWrite(ROT, HIGH);
  digitalWrite(GELB, LOW);
  digitalWrite(GRUEN, LOW);
  delay(5000);

  // Phase 2: Rot-Gelb
  digitalWrite(ROT, HIGH);
  digitalWrite(GELB, HIGH);
  digitalWrite(GRUEN, LOW);
  delay(1000);

  // Phase 3: Grün
  digitalWrite(ROT, LOW);
  digitalWrite(GELB, LOW);
  digitalWrite(GRUEN, HIGH);
  delay(5000);

  // Phase 4: Gelb
  digitalWrite(ROT, LOW);
  digitalWrite(GELB, HIGH);
  digitalWrite(GRUEN, LOW);
  delay(2000);
}

Mini-Simulation

Bereit

Im echten Sketch dauern die Phasen mehrere Sekunden. Die Simulation läuft schneller, damit niemand vor dem Bildschirm Wurzeln schlägt.

Was bedeuten die wichtigsten Befehle?

  • const int ROT = 13; merkt sich: Die rote LED hängt an Pin 13.
  • pinMode(ROT, OUTPUT); macht den Pin zu einem Ausgang.
  • digitalWrite(ROT, HIGH); schaltet den Pin ein.
  • digitalWrite(ROT, LOW); schaltet den Pin aus.
  • delay(5000); wartet 5000 Millisekunden, also 5 Sekunden.

Wie funktioniert eine LED?

LED bedeutet Licht emittierende Diode. Sie lässt Strom im normalen Betrieb nur in einer Richtung gut durch: von der Anode (+) zur Kathode (−).

Wenn Strom durch den Halbleiter fließt, wird ein Teil der elektrischen Energie in Licht umgewandelt.

Ist die LED falsch herum eingebaut, liegt sie in Sperrrichtung. Dann leuchtet sie nicht.

  • Anode (+): meist das längere Bein.
  • Kathode (−): meist das kürzere Bein.
  • Vorwiderstand: schützt LED und Arduino-Pin.

Für die Ampel gilt: Pin → Anode, Kathode → Widerstand → GND.

Leitungsbahnen im Steckbrett

  • Die äußeren Stromschienen sind waagerecht verbunden.
  • Im Mittelfeld sind jeweils fünf Löcher senkrecht verbunden.
  • Der Mittelgraben trennt die beiden Mittelfelder.
  • Bauteile müssen so gesteckt werden, dass sie nicht versehentlich kurzgeschlossen werden.

Merke: Außen waagerecht, innen senkrechte 5er-Bahnen. Das ist der kleine Stadtplan des Steckbretts.
